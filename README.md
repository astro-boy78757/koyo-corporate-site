# 株式会社弘陽 - コーポレートサイト練習用

架空の人材派遣会社「株式会社弘陽」を題材にした、HTML/CSS/JavaScriptの練習用サイトです。

## 構成
- index.html：トップ
- about.html：私たちについて
- business.html：事業内容
- strengths.html：弘陽の強み
- jobseekers.html：求職者向け
- companies.html：企業向け
- company.html：会社概要
- contact.html：お問い合わせ
- assets/css/style.css：共通CSS
- assets/js/main.js：共通JavaScript

## 注意
会社情報・許認可・住所などはすべて練習用の仮データです。
お問い合わせフォームは送信デモで、実際のメール送信処理は実装していません。

## 起動
index.html をブラウザで開けば確認できます。
